# 操作

| 输入或入口 | 行为 |
|---|---|
| 左键、Space、Enter | 先显示完整句子，再次输入推进 |
| Ctrl 按住 | 快进已读内容，遇选项停止 |
| S、A | 切换快进、切换自动 |
| F5、F9 | 快速存档、快速读档 |
| L、R、H | 历史、回滚、隐藏对话界面 |
| Escape | 暂停或返回上一层 |
| Tab、方向键 | 菜单焦点与控件导航 |
| 自动 | 等待文字、语音及自动延时后推进 |
| 历史 | 查看已读正文、重播角色语音 |
| 存档／读档 | 手动、自动与快速槽位 |
| 鉴赏与资料 | CG、音乐、回想、结局、词条与角色 |

音量、语音角色开关、文字速度、字号、高对比及减少动态效果均在设置中调整。当前只提供简体中文，不提供空语言选项。

编辑器内退出游戏使用引擎停止 Play；标题页不会退出整个编辑器。
