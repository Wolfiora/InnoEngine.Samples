# 内容与运行架构

游戏入口为 `Main.iscene → Visual Novel Player GameObject → NovelPlayerComponent`。组件拥有会话、音频、UI、回滚与当前帧，不建立第二套场景或对象生命周期。

`Game/NeonZero.ivnproject` 显式引用章节、变量、角色、舞台、音频、演出、收藏和主题。章节 `.ivnstory` 图是唯一控制流事实；图视图与剧本视图编辑同一份原生资源。

Story 不含运行时脚本。`Tools/Authoring` 是离线创作工具：首次种子导入生成普通原生图，已有游戏拒绝被 seed 覆盖；后续修订通过原生资产服务保存。导出的阅读稿和配音表不参与游戏执行。

角色图集使用插件源区域与部位显隐：六列对应平静、微笑、惊讶、愤怒、悲伤、坚定，两行对应日常和施术。每个姿势包含六个可选择部位，表情只显示对应部位；所有实例继续使用原生角色与舞台机制。

页面采用一个 Cinema 派生主题。组件模板遵循插件现有语义：插入时产生独立可编辑副本，修改模板不会自动覆盖已插入的页面。业务行为由同一套 Player 动作、绑定和控件实现复用。

插件中的 Play 持久化模块在运行场景首次 Update 前注入原生 codec 与存储适配。VN 组件在 Update 中消费输入、发起存储、排版并准备不可变画面；渲染回调只采样输入和提交该画面。异步存储后续请求排队回到原生更新作用域发起，避免沿用已退休的帧绑定。

原生键盘读取正式 `Input.snapshot`，继续由引擎 Game View 焦点规则过滤；组件按输入帧只转交一次。视口输出提供鼠标坐标、滚轮和按钮，避免从只含鼠标的输出中猜测键盘。普通阅读确认与显式控件导航分别遵守当前输入归属。

使用过的音频通过正式 `Audio.PreloadAsync` 保留于当前会话，采用一致的 Stream 加载策略。快进停止声道，不抢先销毁仍在准备的音频源；会话退场后释放已完成的预加载，并取消尚未完成的请求。输出的可释放生命周期由原有音频 Director 所有，缓存与设备仍属于引擎。

持久化继续使用引擎 Serialization、Storage 和插件 SaveService。没有 JSON、私有二进制格式、数据库或外部 TTS 服务。
