# 素材与来源

## 图片

背景、角色图集、头像、CG 和封面使用内置 imagegen 工具为本案例生成，角色均为原创虚构人物。最终 PNG 在 `Assets/Art`，运行时无远程素材请求。设计提示和对应文件见 `Production/Art/GenerationPrompts.md`。

## 角色配音

通过本机 Windows Media SpeechSynthesis 离线生成：林澈使用 Microsoft Yaoyao，许岚使用 Microsoft Huihui，沈砚使用 Microsoft Kangkang。项目提供生成后的 WAV，不提供或打包系统声音模型。旁白不配音。

## 音乐

Cipher、Heart of Nowhere、Clash Defiant、Volatile Reaction：Kevin MacLeod，incompetech.com。原始 MP3 直接经引擎音频导入器导入，未重新编码。完整署名见 `Licenses/MusicAttribution.txt`。

Dawn、粒子精灵、内置组件起点、字体与 Shader 来源于 InnoEngine.VisualNovel 正式资源，通过原生插件引用使用。其所有权及相应说明沿用插件。

## 环境音和音效

本案例的三段环境循环及十二个剧情效果由离线工具进行噪声、滤波、包络和谐波合成。它们是明确的合成设计音效，不是角色语音替代品。
