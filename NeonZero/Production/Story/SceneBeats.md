# 分镜与演出职责

| 章节 / 场景 | 剧情目的 | 画面和声音 | 交互 |
|---|---|---|---|
| 第一章 / 雨夜街道 | 介绍林澈及停摆城市 | StreetRain、雨声、开场镜头 | 正常阅读 |
| 第一章 / 地铁站台 | 许岚登场、第一次夜潮战斗 | MetroPlatform、战斗姿势、冲击音、镜头震动 | 护送乘客或切断线路 |
| 第一章 / 灯巷 | 建立临时同盟 | LampAlley、灯火粒子、RainLamp CG | 解锁第一张 CG |
| 第二章 / 旧灯铺 | 解释灯术与共鸣代价 | LampWorkshop、练习演出、日常音乐 | 共同承担或调查旁路 |
| 第二章 / 钟楼 | 沈砚拒绝放下过去，夜潮突破 | ClockTower、破裂音、战斗音乐、震动 | 线索汇合 |
| 第三章 / 零时核心 | 三人合作，最终攻防与反击 | ZeroCore、粒子、镜头片段、魔法音效、ResonantDawn CG | 广域共鸣或完成封印 |
| 第三章 / 城市灯海 | 万家灯火的尾声 | CityLights CG、黎明音乐 | 解锁结局一 |
| 第三章 / 清晨重逢 | 黎明仍至的尾声 | MorningReunion CG、黎明音乐 | 解锁结局二 |
| 尾声 / 街道与屋顶 | 回收怀表和修灯线索 | StreetDawn / RooftopDawn | 制作名单后返回标题 |

演出由原生节点和资源承担。片段目前主要使用镜头通道与震动；角色姿势和表情由舞台节点切换，入退场及转场复用舞台和溶解机制。没有另写战斗控制器。不能把资源命名理解为每一种角色入场动画都已单独实现。
