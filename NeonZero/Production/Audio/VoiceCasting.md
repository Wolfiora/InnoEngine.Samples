# 配音与录制替换

| 角色 | 当前离线中文合成声线 | 表演方向 |
|---|---|---|
| 林澈 | Microsoft Yaoyao | 快速、直接，战斗时保持清晰 |
| 许岚 | Microsoft Huihui | 克制、清楚，逐渐接受帮助 |
| 沈砚 | Microsoft Kangkang | 沉稳，承认错误后语气放松 |

127 条角色台词由 Windows 公共语音合成接口离线导出为 WAV；运行时播放普通音频资产，不依赖在线 TTS 或本机声线。旁白不配音。合成语音不保证情感、重音和多人对话的专业配音效果。

文本身份是 `nz.ch01-xxx` 等稳定 textId。源章节的 `voiceCueId` 指向同名原生提示资源。替换录音时保留 textId 与路径，重新原生导入 WAV 即可；不要按阅读稿行号重命名。

修改台词后，先从当前原生图导出和审核配音表，再生成或录制变化的行。`Bake-Voice.ps1` 会跳过已有文件；需要重录时明确替换对应行，不批量覆盖原有录音。
